# 分布与密度

## Beeswarm plot｜蜂群图

- **官方类别**：distributions / time series / proportions。
- **应用**：点沿连续轴分布，纵向错开避免重叠。
- **数据与计算/编码说明**：连续数值+点的避让排布，大小/颜色可扩展。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/beeswarm/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/beeswarm/dimensions.js)。

## Box plot｜箱线图

- **官方类别**：distributions。
- **应用**：用最小值、Q1、中位数、Q3、最大值概括分布。
- **数据与计算/编码说明**：必填数值Y，可选组别；五数概括。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/boxplot/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/boxplot/dimensions.js)。

## Violin plot｜小提琴图

- **官方类别**：distributions。
- **应用**：形状宽度对应某数值处的观察密度。
- **数据与计算/编码说明**：定量分布和密度形状。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/violinplot/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/violinplot/dimensions.js)。

## Hexagonal binning｜六边形分箱图

- **官方类别**：correlations / distributions。
- **应用**：密集二维散点用六边形格网分箱计数。
- **数据与计算/编码说明**：点按六边形汇总，颜色或面积表达点数。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/hexagonalBinning/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/hexagonalBinning/dimensions.js)。

## Contour plot｜等值密度图

- **官方类别**：correlations / distributions。
- **应用**：估计二维点云密度以减轻严重重叠。
- **数据与计算/编码说明**：散点密度估计与等值线/面。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/contourPlot/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/contourPlot/dimensions.js)。
