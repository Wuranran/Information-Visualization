# 层级与比例

[返回统计图形索引](README.md)

**资料属性**：英文图表名称和类别来自官方元数据；中文应用说明为官方description的翻译性摘要；下文涉及案例对应及设计解释均为本仓库归纳，**不代表原案例一定由RAWGraphs生成**。

## Treemap｜矩形树图

- **官方类别**：hierarchies / proportions。
- **应用**：矩形面积按数量变化，包含关系展示层级。
- **数据与计算/编码说明**：必填多层Hierarchy；数值Size可选、默认sum；案例007。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/dimensions.js)。

## Circle Packing｜圆形打包图

- **官方类别**：hierarchies / proportions。
- **应用**：圆的嵌套表现树结构，叶节点面积显示数值。
- **数据与计算/编码说明**：嵌套关系+面积；案例005套圆但尚未证实父子层级。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/circlepacking/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/circlepacking/dimensions.js)。

## Circular dendrogram｜环形树状图

- **官方类别**：hierarchies / proportions。
- **应用**：从中心根节点向外辐射展示层级。
- **数据与计算/编码说明**：径向节点与连接边，可附加点面积与色彩。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/circularDendrogram/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/circularDendrogram/dimensions.js)。

## Linear dendrogram｜线性树状图

- **官方类别**：hierarchies / proportions。
- **应用**：从左到右沿树枝连接根与叶节点。
- **数据与计算/编码说明**：父子树关系与点、线；层级候选形态。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/dendrogram/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/dendrogram/dimensions.js)。

## Sunburst diagram｜旭日图

- **官方类别**：hierarchies / proportions。
- **应用**：中心根节点向外以同心弧段展示层级和数值。
- **数据与计算/编码说明**：层级与弧段角度；不能单凭环形造型判定类型。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/sunburst/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/sunburst/dimensions.js)。

## Treemap (Voronoi)｜Voronoi树图

- **官方类别**：hierarchies / proportions。
- **应用**：Voronoi镶嵌单元呈现叶节点大小。
- **数据与计算/编码说明**：迭代面积估计；官方提醒面积可能不完全与数值一致。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/voronoitreemap/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/voronoitreemap/dimensions.js)。

## Pie chart｜饼图

- **官方类别**：proportions。
- **应用**：圆形扇区表达整体各部分比例。
- **数据与计算/编码说明**：分类构成与合计；案例006局部扇区可对照，但数值未逐一核实。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/piechart/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/piechart/dimensions.js)。
