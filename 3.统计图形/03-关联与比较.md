# 关联与比较

[返回统计图形索引](README.md)

**资料属性**：英文图表名称和类别来自官方元数据；中文应用说明为官方description的翻译性摘要；下文涉及案例对应及设计解释均为本仓库归纳，**不代表原案例一定由RAWGraphs生成**。

## Bar chart｜条形图

- **官方类别**：correlations。
- **应用**：类别及对应数量比较。
- **数据与计算/编码说明**：长度或宽度编码数值；案例004辅助条形比较。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchart/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchart/dimensions.js)。

## Multi-set bar chart｜分组条形图

- **官方类别**：correlations / proportions。
- **应用**：每个类别下并列多个定量字段。
- **数据与计算/编码说明**：多个数值系列按类别分组。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchartmultiset/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchartmultiset/dimensions.js)。

## Stacked bar chart｜堆叠条形图

- **官方类别**：correlations / proportions。
- **应用**：同类别不同数量系列叠加。
- **数据与计算/编码说明**：部分与总体的堆叠比较。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchartstacked/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchartstacked/dimensions.js)。

## Bubble chart｜气泡图

- **官方类别**：correlations / proportions。
- **应用**：散点基础上附加大小与色彩维度。
- **数据与计算/编码说明**：二维连续坐标+大小/色彩，区别于真实地理比例圆。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/bubblechart/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/bubblechart/dimensions.js)。

## Matrix Plot｜矩阵图

- **官方类别**：correlations / time series / proportions。
- **应用**：两个类别维度置于横纵轴，交叉单元编码关联。
- **数据与计算/编码说明**：单元的面积和颜色可映射数量。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/matrixplot/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/matrixplot/dimensions.js)。

## Parallel coordinates｜平行坐标图

- **官方类别**：correlations / distributions。
- **应用**：一条折线跨多个连续数值维度。
- **数据与计算/编码说明**：多个轴对应多变量；每个数据记录一条线。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/parallelcoordinates/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/parallelcoordinates/dimensions.js)。

## Radar Chart｜雷达图

- **官方类别**：correlations。
- **应用**：从中心向外的多个连续数值轴，且使用统一尺度。
- **数据与计算/编码说明**：径向轴位置和连接线。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/radarchart/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/radarchart/dimensions.js)。

## Convex hull｜凸包图

- **官方类别**：correlations / proportions。
- **应用**：给某类二维散点构造最小凸形边界。
- **数据与计算/编码说明**：二维点+类别，计算凸包区域。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/convexHull/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/convexHull/dimensions.js)。

## Voronoi Diagram｜Voronoi图

- **官方类别**：Correlations（源码原样）。
- **应用**：按二维点间距离划分最近邻区域。
- **数据与计算/编码说明**：二维点+Voronoi空间划分，非地理型的充分条件。
- **来源**：[官方metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/voronoidiagram/metadata.js) · [数据字段dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/voronoidiagram/dimensions.js)。

## 解释范围

上述“数据与计算/编码说明”仅在原始源码明确说明默认聚合或字段时视为已核实；其他为一般图形编码原理的研究性概括，实际实现须逐项核对对应图表的dimensions.js、mapping.js与实际数据。小图、路径和插画不应在未核实的情况下被认定为特定RAWGraphs统计图。
