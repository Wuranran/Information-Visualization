## 与五大主分类的关系

- 编年型：历史或过程的不可颠倒顺序优先；时间线、折线或甘特图均非充分条件。
- 层级型：上位→下位；矩形树图、圆形打包、树状图是可借鉴形式，插画也可以承载非数值层级。
- 编目型：同一作品由编年顺序与层级组织复合而成，不是某一种RAWGraphs统计图的同义词。
- 字母型：多个独立、字段一致且均衡排列的数据组；组内可有时间轴，组间不具有必需的不可逆发展过程。
- 地理图型：需要真实地理地图为中心组织；当前注册清单不包含专门的地理地图图表类型，不能将网络图或国家名称直接当作地理图型。
