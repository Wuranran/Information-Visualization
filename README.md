# Information-Visualization

信息可视化分类与案例研究仓库。

## 目录
- [1.五种分类](1.五种分类/)：编年型、层级型、编目型、字母型、地理图型的概念总文档、示例图与案例分析。
- [2.常用信息图形案例库](2.常用信息图形案例库/)：按词云图、HOW-TO信息图、文字型信息图等具体类型存储原图与分析。

## 收录流程
1. 保存用户上传的**原始图片**，不得以搜索或生成图片替换。
2. 先判断五大主类型，再判断常用类型；允许跨类型标签，但须确定主分类并说明依据。
3. 按六维分析：数据结构、统计图形应用、视觉编码、信息框架、叙事框架、信息图形类型学分类。
4. 将完整案例报告及原图归入常用案例库的具体类型目录；必要时在五大分类目录建立案例索引/分析副本。
5. 更新对应五大分类的概念及说明总文档，记录案例编号、分类依据与边界。
6. 无法判断时标注“待定”，不强行分类；来源与作者未知时注明待核实。

目前只建立目录和模板，尚未录入新的案例原图。
