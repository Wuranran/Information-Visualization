# Information-Visualization

信息可视化分类与案例研究仓库。

## 目录
- [1.五种分类](1.五种分类/)：编年型、层级型、编目型、字母型、地理图型的概念总文档、示例图与案例分析。
- [2.常用信息图形案例库](2.常用信息图形案例库/)：以「案例编号-《具体名称》-五大分类-主要统计图形」统一命名，案例001—010平铺归档，用户原图集中存储于共享示例图目录。
- [3.统计图形](3.统计图形/)：根据RAWGraphs应用注册清单与官方元数据建立32项图表名称、类别、应用、计算/编码参考；独立维护研究方法和案例引用规范。

## 收录流程
1. 保存用户上传的**原始图片**，不得以搜索或生成图片替换。
2. 先判断五大主类型，再判断常用类型；允许跨类型标签，但须确定主分类并说明依据。
3. 按六维分析：数据结构、统计图形应用、视觉编码、信息框架、叙事框架、信息图形类型学分类。五种分类定义文档同时以A数据逻辑、B统计图形与计算、C视觉编码、D数据/信息架构、E视觉叙事架构维护。
4. 将完整报告以四段式名称直接保存于常用信息图形案例库；原始 JPG 集中保存至该目录的示例图子目录，并维护五大分类的案例索引。
5. 更新对应五大分类的概念及说明总文档，记录案例编号、分类依据与边界。
6. 无法判断时标注“待定”，不强行分类；来源与作者未知时注明待核实。

## 案例引用与来源说明

- 案例库统一使用**案例001—010**的连续编号进行分析、比较和索引，不设置主证据、辅助证据或U／E等级。
- 各作品原图或原作者的来源信息仍保留在相应案例报告中，方便核查，不用于区分案例地位。
- RAWGraphs 官方资料是统计图形技术参考；从案例归纳的方法与待验证结论另行说明。
- [研究方法与案例引用规范](3.统计图形/研究方法与案例引用规范.md)。

## 更新原则

新增案例时，核实原图、完成六维分析、归档并更新对应五型A—E定义；涉及边界争议则列出证据，待用户确认后再修改已确认主分类。这里的“持续更新”指**每次新增/修订案例时同步更新文档**，不代表已经开启后台自动监测。
