## 0. 五大类型判断（数据逻辑优先）

**主分类：层级型。**

核心数据逻辑为：

**全球前100位富豪财富集合 → 国家分组 → 各国富豪个人净资产。**

上位分类和下位成员具有明确的组织方向，国家与个人的归属关系不能任意对调；不同国家内部可以同时包含多个富豪和多个财富数据。这里的**不可逆**指上位—下位组织角色不能随意倒置，**不是历史时间上的不可逆**。

| 类型 | 判断 | 依据 |
|---|---|---|
| 编年型 | 不符合 | 作品不是按时间或因果过程单向推进；静态日期只是数据快照 |
| **层级型** | **符合** | 总体→国家→个人的明确嵌套归属关系 |
| 编目型 | 不符合主逻辑 | 不存在与层级结构共同主导的编年式过程顺序 |
| 字母型 | 不作为主分类 | 尽管有许多可比较矩形，但组间存在明确的国家包含层级 |
| 地理图型 | 不符合 | 国家只是分组字段，图中没有地理地图形状或空间定位 |

## 1. 数据结构

本案例为**多层级、定量型集合数据**：

| 数据单位 | 字段与数据类型 | 组织关系 |
|---|---|---|
| 总体 | 入选富豪集合；总体财富（定量） | 上位全集 |
| 国家 | 国家名称（名义型）及组内总财富（可汇总定量） | 中间层级 |
| 个人 | 富豪姓名、财富金额、排名 | 下位条目 |
| 日期 | 数据快照日期（时间标签） | 来源元数据，不构成时间序列 |

2021-12-15的静态图显示前100名合计约4.536万亿美元。原作品可调整人数并切换国家或行业分组，所以报告只对当前选定的**国家分组静态版**作类型判断。

## 2. 统计图形应用

**主要图形：矩形树图（Treemap）**。用矩形面积呈现各富豪的相对财富大小，同一国家的个人矩形在空间中组成整体国家区块；从而在同一平面同时呈现数量比较和层级归属。

- **矩形面积**：用于财富数量比较；明显不同于矩形条形图中的单一长度编码。
- **嵌套分组**：国家区域包含个人矩形，支持由总体向局部细分。
- **交互模式**：作者页面支持选择人数、切换国家/行业分组、局部放大及悬停读取更多信息。静态截屏无法完整保存这些互动行为。

## 3. 视觉编码

| 视觉变量 | 对应数据 | 作用 |
|---|---|---|
| 矩形面积 | 个人净资产金额 | 显示定量差异 |
| 区块包含 | 国家→个人归属 | 表现层级数据结构 |
| 色相 | 不同国家类别 | 区分群组 |
| 区块相对位置 | 矩形布局算法和分组 | 优化面积利用，非地理位置、非时间轴 |
| 文本 | 姓名、排名及财富金额 | 支持准确识别 |
| 边框 | 矩形间的区隔 | 强化分组和对象界限 |

此图的视觉编码虽不是传统线性树枝图，但属于**层级组织的可变表现形式**；五大分类不应只由线性或矩形外形决定。

## 4. 信息框架

**总体标题及信息 → 国家区块 → 个人矩形**。图形以一个完整矩形视图区为整体容器，内部由国家分区和个人矩形构成嵌套布局。较富有的个人占据更大面积，小值群体则密集分布在较小区域。

## 5. 叙事框架

属于**由整体到局部的探索式比较叙事**。首先感知财富在少数大矩形中的高度集中，再比较不同国家所占面积，最后查阅个人金额或排名。没有固定时间叙事；读者可以独立选择国家或个人深入探索。

## 6. 信息图形类型学分类

- **五大主类型**：**层级型信息图**。
- **核心数据逻辑**：总体富豪财富集合→国家分组→个人富豪数据，呈有方向的上位—下位归属关系。
- **数据维度**：不同国家包含数量不等的多个个人，个人再携带财富金额、排名等关键字段。
- **视觉编码**：面积、颜色、嵌套矩形及文字；突出层级型外观的高度可变性。
- **信息框架**：嵌套包含式矩形树图。
- **叙事**：探索式财富结构与量级比较。
- **常用形式**：矩形树图（Treemap）。

### 与案例001的对比

案例001《The Treehouse of Adulthood》以**成年时期→生活事件**形成概念性层级；本案例则以**总体→国家→富豪个人**形成可用类别字段和定量数据验证的明确分组层级。因此，本案例更适合作为**标准数据层级与面积编码**的典型参考。

## 优点与局限

**优点**：同时展示多层归属与个人财富差异；无需多个分图即可观察大规模分类数据；交互模式支持细节探索。

**局限**：较小矩形标签不易阅读；面积不如统一坐标长度便于精确比较；颜色类别较多；不同交互分组会改变结构表现，不能把某一静态布局当作唯一版本；数据具有时点性，不应直接作为当前排名使用。
