# 矩形树图（Treemap）

## 类型说明

使用不同面积的矩形表达定量数据，并通过嵌套、分组或空间邻接展示类别归属。该目录是**常用统计图形形式**，并非五大主分类；具体归属仍由数据逻辑判断。
