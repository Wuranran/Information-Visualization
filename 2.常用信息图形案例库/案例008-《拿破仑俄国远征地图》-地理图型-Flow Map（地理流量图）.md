## 0. 五大类型判断：数据逻辑优先，地理图形为必要条件

**正式主分类：地理图型信息图。**

这张作品明确使用地理地图的形式，以部队经过的城市、道路方向和空间路径为核心骨架，将数量、行军方向和撤退时的日期、温度叠加其上。地理路线不是装饰，而是决定信息连接与读取方式的组织结构。

| 类型 | 结论 | 判断依据 |
|---|---|---|
| 编年型 | 局部具有 | 行军与撤退具有历史先后，但全图还需要具体地理路径才能成立 |
| 层级型 | 不作为主分类 | 兵力支路不构成整体主导的上下位主题层级 |
| 编目型 | 不作为主分类 | 多变量和时间叙事并不能直接证明具有“编年型＋层级型”的共同主导逻辑 |
| 字母型 | 不符合 | 地理路径与军队行进过程连续关联，非多个可交换的同构数据组 |
| **地理图型** | **符合** | **地理位置、城市及空间路线为主要图形组织形式** |

**与案例004不同**：案例004以宋代历史地图承载文化人物与区域统计，案例008将地理位置直接与兵力数量、行军方向及气温相结合。

## 1. 数据结构

这是一张**地理空间主导的多变量、连续路径数据**：

| 数据字段 | 数据类型 | 数据关系 |
|---|---|---|
| 地点及空间位置 | 地理数据 | 行军路线经过的城市和地点 |
| 军队人数 | 连续定量数据 | 在各地理节点对应的兵力大小 |
| 行进方向 | 方向/类别数据 | 进入俄国与撤出俄国的路线 |
| 时间日期 | 时间型 | 与撤退路线和温度记录对应 |
| 气温 | 连续定量数据 | 在撤退时相关日期与地点的观测值 |
| 部队分支及汇合 | 路径关系 | 部分部队离开主线或重新加入的线路 |

原图所给的示意军队人数由最初的约422,000人缩减至末端约10,000人。**这是米纳德图中对应军队与线路的统计叙述，不能直接等同于1812年整个战役的伤亡总数。**

## 2. 统计图形应用

1. **地理流量图**：用沿地理路径行进的连续宽带代表军队。
2. **变宽流带编码**：用宽度表现兵力人数；原作图例记载按每1毫米宽带表示1万人进行绘制。
3. **地理路径分支图**：当部队分离或汇集时，流带出现相应分叉或连接。
4. **温度折线图**：地图下方记录撤退过程相关地点的温度，日期与地理位置相互参照。

下方气温的单位为**列氏温标（°Réaumur，°R）**，非摄氏度。按温差比例，−30°R相当于约−37.5°C；不能原样将其标注成−30°C。

## 3. 视觉编码

| 视觉变量 | 数据表达 | 设计作用 |
|---|---|---|
| 米黄色流带 | 向俄国推进的部队 | 与撤退路线形成方向区分 |
| 黑色流带 | 撤退的部队 | 表现返回方向和损失 |
| 流带宽度 | 军队人数 | 强调军队规模持续变化 |
| 路线和地名 | 地理位置 | 确定空间组织 |
| 分叉、汇合 | 部队行军支路 | 表示路线关系 |
| 数字注释 | 特定节点的兵力 | 精确读取数量 |
| 下方折线、温度数字和日期 | 撤退气温与相关日期 | 展现另一条时间/温度解释层 |

流带宽度具有明确的量化编码目的，但现代屏幕上显示的毫米宽度取决于缩放，不可简单按屏幕像素直接恢复人数。

## 4. 信息框架

**上层：地理空间及兵力流带；下层：按相应地点对齐的撤退温度曲线。**

上图是主要信息载体；下图通过地理位置的垂直对照，补充气温与时间。空间、数量与时间在同一张页面里形成相互关联的双层框架。

这一框架并非严格按一个方向从左到右阅读：米黄色带大致向东推进，黑色带则沿返回方向阅读；下方气温曲线跟随撤退方向，主要由右向左阅读。

## 5. 叙事框架

采用**地理路径驱动的历史过程叙事**：

**进入俄国 → 向莫斯科推进 → 兵力减少 → 从莫斯科撤退 → 军队持续缩减 → 返回时兵力大幅减少。**

读者通过流带由宽到窄，直观感知兵力损失，再观察下方温度曲线理解相关环境条件。**兵力减少与严寒同时出现，不能仅据图像断定每一项损失的具体原因；原图不是完整的伤亡因果模型。**

## 6. 信息图形类型学分类

- **五大主类型**：**地理图型**。
- **核心数据逻辑**：以地理位置与连续路线为主轴，关联兵力数量、行动方向、日期和气温。
- **数据维度**：具有空间、时间、数量、方向和气温的多维复合结构。
- **统计图形**：地理流量图、变宽流带、温度折线图。
- **视觉编码**：地理空间位置、流带宽度、颜色、路径方向、数值与折线。
- **信息框架**：地理行军路线主图＋撤退温度对齐附图。
- **叙事框架**：沿军队路线展开的历史发展与损失叙事。
- **常用图形形式**：地理流量图／历史兵力变化地图。
