# 插画隐喻型信息图：类型说明

## 工作定义
以具象插画或场景为主体，借助隐喻、象征、拟人、物体替代和文字标注组织并解释信息。常用于定性主题与概念叙事，不必包含统计图形。

## 判定标准
1. 插画及其象征关系是主要信息载体，而非仅为装饰。
2. 画面中的物件、场景或空间位置对应概念含义。
3. 需区分隐喻关系与真实数值、地理、时间或层级数据关系。
