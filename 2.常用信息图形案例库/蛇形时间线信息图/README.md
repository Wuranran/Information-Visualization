# 蛇形时间线信息图

## 图形形式说明

以连续弯曲、折返或蛇形路线串联一系列具有时间或过程先后关系的节点，常用于在有限画面中组织较长的历程。该类别描述**常用图形形式**，不是五大类型本身；五大主分类依具体作品的数据逻辑判断。
