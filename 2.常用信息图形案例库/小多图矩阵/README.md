# 小多图矩阵（Small Multiples）

## 图形形式说明

使用统一或基本统一的坐标、字段、图形语法重复绘制多个小型统计图，并以多行多列的矩阵形式组织多组信息。小多图是一种**常用图形形式**，其五大主分类需由实际数据逻辑决定，不自动等于字母型。

## 案例索引

- [案例009｜How We Spend Our Days](案例009-How-We-Spend-Our-Days-信息图分析报告.md)：**字母型**。多种日常活动使用同构的年龄—平均用时折线图，以多列多行矩阵均衡排布；每组实线为周末、虚线为工作日。
