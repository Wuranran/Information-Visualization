# 历史文化地图型信息图

## 类型说明

以**历史或文化主题的地理地图**为主要视觉组织框架，组合人物、地名、历史信息、统计图形及文化文本等内容。本类别描述**常用图形表现形式**；五大主分类仍需依据每件作品的数据逻辑与相关类型的必要条件分别判定。
