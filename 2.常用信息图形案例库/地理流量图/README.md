# 地理流量图

## 图形形式说明

以真实地理空间中的点位和路线为基础，使用具有数量编码的流带表现沿路线移动的对象、规模或变动。该目录属于**常用图形表现形式**，不是五大类型的自动判定标准；五大类型仍以作品的核心数据逻辑和必要形式条件判断。
