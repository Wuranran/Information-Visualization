# 常用信息图形案例库

## 文件命名规则

每个案例直接保存于本目录，统一格式：

**案例编号-《信息图的具体名称》-五大分类-主要统计图形名称.md**

名称引用报告中已有的原题或中文分析题。**统计图形一栏如实记录：**采用标准统计图则写其名称；没有标准定量统计图则用「无标准统计图形」；主要是非统计时间路线但含辅助统计时注明「无核心标准统计图形（辅助……）」；复杂案例可列出几种实际可识别的图形。这里的图形名称不表示原作者使用 RAWGraphs。

现有案例编号从001至010，不区分主／辅助证据等级。报告正文保留完整六维分析，原图均集中在 [示例图](示例图/)；网络作品仍使用原作者或可靠来源的外部链接。

## 后续更新原则

新增案例按相同格式命名后直接加入本目录，不因主题或视觉形式新建一个仅收录单个案例的文件夹。同步更新对应五类的 A—E 文档、案例索引与 [3.统计图形](../3.统计图形/README.md) 的图形机制参照。没有依据的统计图名称不强行套用。
