## 0. 五大类型判断：数据逻辑优先

**正式主分类：字母型信息图。**

作品将“睡眠、工作、教育、休闲、社交、运动、照护、消费、电话、志愿活动”等日常活动分别作为独立数据组，每组用基本相同的二维折线图表示**年龄与每日平均活动时长**的关系，并按**工作日／周末**分别绘制曲线。不同活动组在页面上均衡排布，组与组之间不存在必须遵循的过程先后顺序。

| 五大类型 | 判断 | 核心依据 |
|---|---|---|
| 编年型 | 不符合整体主逻辑 | 图内年龄轴具有方向，但活动组之间没有不可逆的发展过程 |
| 层级型 | 不作为主分类 | 活动类别之间主要是并列关系，没有整体主导的上下位层级组织 |
| 编目型 | 不符合 | 未形成编年型与层级型共同主导的数据逻辑 |
| **字母型** | **符合** | 多个格式基本统一的数据组以矩阵方式均衡排布，整体不依赖严格顺序 |
| 地理图型 | 不符合 | 不使用地理地图形式 |

**重要边界：**“每一张小图内的年龄变化”不等于“活动组彼此构成编年型历史序列”。分类根据**整张作品的主导数据逻辑**判断。字母型也不意味着必须按照A—Z顺序排列。

## 1. 数据结构

属于**多组同构、定量、年龄趋势比较型数据**：

| 数据字段 | 类型 | 作用 |
|---|---|---|
| 活动类别 | 名义型 | 指定彼此独立的比较组 |
| 年龄 | 定量有序型 | 在各组内形成横坐标 |
| 平均每天用于该活动的时间 | 连续定量型 | 在各组内形成纵坐标 |
| 工作日或周末 | 二元类别型 | 为每组提供两条比较曲线 |
| ATUS采集期间 | 数据来源时间范围 | 数据来自2003—2015，非直接在全图展示一条年度时间线 |

逻辑结构为：

**活动类别 A → 同一组字段（年龄、活动时长、工作日／周末）**

**活动类别 B → 同一组字段（年龄、活动时长、工作日／周末）**

**活动类别 C → ……**

不同组可交换展示位置而不改变每个组本身的数据意义。这里的年龄分组统计是不同年龄受访者的横截面比较，不应直接推断为追踪同一批受访者一生的纵向观测。

## 2. 统计图形应用

- **小多图（Small Multiples）**：多块小型折线图沿网格均衡排列，各小图对应一种活动。
- **双序列折线图**：每块图内以实线表示**周末**，虚线表示**工作日**。这一约定可由Adafruit的原作说明核实。
- **年龄—时长趋势图**：横轴为年龄，纵轴为平均每日用时，不同活动展示不同年龄段的趋势形状。

**比较限制**：不同活动小图的纵轴刻度范围可变化。不同图形之间若仅比较曲线的垂直高度、而不核对各自纵轴数值，可能得到错误的活动用时比较；跨图比较趋势形状较为直观。

## 3. 视觉编码

| 视觉变量 | 对应内容 | 作用 |
|---|---|---|
| 每个小图的占位 | 活动类别 | 区分多个独立组 |
| 横轴位置 | 年龄 | 表达组内有序变化 |
| 纵轴位置 | 每日平均用时 | 表达定量水平 |
| 实线 | 周末 | 组内类别比较 |
| 虚线 | 工作日 | 组内类别比较 |
| 不同线条色彩 | 不同活动模块 | 辅助识别类别与分组 |
| 重复图形结构 | 同构的活动数据 | 强化统一比较编码 |
| 小图标题和刻度 | 活动和数量单位 | 支持识别、查读 |

颜色主要用于区分活动小图；线型则跨整个作品保持相同的工作日／周末语义。

## 4. 信息框架

采用**多列多行的小图矩阵布局**。每块小图都包含活动名称、年龄横轴、用时纵轴，以及代表周末和工作日的两条折线。统一的视觉语法让读者在同一页面上阅读多类活动的变化模式。

矩阵位置不是地理坐标，也不是构成单一路径的历史发展顺序。小图之间具有高独立性，因此符合字母型“数据组均衡排布”的要求。

## 5. 叙事框架

作品采用**横向探索式比较叙事**，没有唯一固定阅读路线。

读者可以：
1. 在工作、教育等小图中观察年龄相关的日常时长变化。
2. 选择周末和工作日两条曲线，识别同一活动在不同日期类型中的差异。
3. 转向运动、休闲、社交等其他活动，比较不同活动的趋势形状。

这些观察描述的是图形允许的阅读方法，不代表所有观察到的年龄变化都具备因果解释。ATUS本身是调查数据，聚合趋势不等于同一人的个人生命史。

## 6. 信息图形类型学分类

- **五大主类型**：**字母型**。
- **核心数据逻辑**：多个相互独立、格式统一的活动数据组并列展示，整体不强调严格的过程先后。
- **数据维度**：所有组使用相同的年龄、平均活动用时、日期类型字段，便于组间比较。
- **统计图形**：小多图及双曲线折线图。
- **视觉编码**：统一坐标结构、颜色区分、实虚线对照、多组矩阵位置。
- **信息框架**：均衡排布的多列小图阵列。
- **叙事框架**：非固定顺序的多类别探索比较。
- **常用图形形式**：小多图矩阵（Small Multiples）。

### 与案例005《North America》的比较

| 对比项 | 案例005 | 案例009 |
|---|---|---|
| 比较对象 | 国家／地区 | 日常活动 |
| 每组图形形式 | 嵌套圆形＋名称数值 | 双曲线折线图＋标题刻度 |
| 组内数据 | 数值及可能的附加变量 | 年龄、时长、日期类型 |

两张图都以**数据组之间的独立、同构、非不可逆关系**为主导，但视觉编码和单组信息丰富度不同。

## 优点和局限

**优点**：适合一次比较多种类别的变化曲线；重复图形规则降低学习成本；工作日与周末的统一线型支持跨图理解。

**局限**：小图尺寸较小，精确数值阅读困难；各小图纵轴可能不同，不宜只按曲线高度直接比较；不同年龄群体的调查平均值不能直接作为同一个人随年龄变化的个体轨迹；图像展示的是历史调查数据，不代表2026年现状。
