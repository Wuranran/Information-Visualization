# 人体剖面隐喻型信息图

## 类型说明

以人体外形及剖面结构为主要视觉容器，将人体内部机制、相关过程或主题数据转化为具象场景；此处的“人体剖面隐喻型”描述**常用图形表现形式**，不是五大类型之一。

五大主分类仍以作品的**数据逻辑**判断，可因不同作品而不同。不能仅凭人体剖面样式确定其五大主分类。
